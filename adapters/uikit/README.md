# JulianKit for UIKit

The Julian look as a Swift package for iOS: the foundations as tokens, plus the flagship control. A first pass—foundations and a button, not the full component set.

## Install

In Xcode: File → Add Package Dependencies → add this repository's URL and set the package path to `adapters/uikit`, or drag the `adapters/uikit` folder in as a local package. In a `Package.swift`:

```swift
.package(url: "https://github.com/juliankellydesign/julians-guide-to-interfaces", branch: "main")
```

Then `import JulianKit`.

## What's inside

| File | Carries |
| --- | --- |
| `JulianColors.swift` | The gray and six color scales as `UIColor` (`JulianScale`), and the semantic roles as dynamic colors (`JulianColor`)—generated from `data/foundations.json` |
| `JulianTypography.swift` | The major-second type scale from base 17, the tracking taper (in percent and in points for `.kern`), grid-snapped line heights, and the weight roles |
| `JulianSpacing.swift` | The spacing ladder with the 1pt hairline, modal padding, the radius scale, and the nested-corner formula |
| `JulianMotion.swift` | Timing: 200ms ceiling, the 0.9 press scale at 100ms, the 48-frame loop scaffold, and the reduce-motion check |
| `JulianButton.swift` | The button spec: five named sizes, three styles, radius 10, press scale, 40% disabled opacity |

Use semantic roles, not raw scale values—`JulianColor.textPrimary`, not `JulianScale.gray1000`. The raw scales are the definition layer; components consume roles.

```swift
let save = JulianButton(style: .primary, size: .l)
save.setTitle("Save", for: .normal)

view.backgroundColor = JulianColor.canvas
label.font = JulianType.font(step: 2, weight: JulianType.headerWeight)
label.textColor = JulianColor.textPrimary
```

## First-pass boundaries

- **Dark mode is mechanical.** The semantic roles resolve in dark mode by mirroring the scales with elevation preserved. The guide documents no dark-mode opinion yet; treat dark output as a placeholder.
- **One control.** Lists, navigation bars, tab bars, search—the structural half of an iOS app—are not specified yet; see the platform-coverage table in [`guide/design-system/README.md`](../../guide/design-system/README.md#platform-coverage). Where the spec's dimensions disagree with platform conventions (M height 40 vs. the 44pt target minimum), that question is documented as open. `JulianButton` defaults to L (48) on touch for this reason.
- **No focus ring.** The button's focus-visible treatment is unimplemented.
- **System font.** Karl is personal and not distributed. The weight roles adapt to whatever typeface you set.

## Regeneration

`JulianColors.swift` is generated by [`scripts/generate-adapters.py`](../../scripts/generate-adapters.py) from `data/foundations.json`; don't edit it by hand. The other files are maintained against the guide's methods—if a documented value changes, they change with it.
