Principle № 001

Everythingearns its place.

Every element in an interface should serve a purpose.

This is not an argument for stark minimalism. Flourishes are welcome when they communicate something.

01Core principle

Purpose before polish.

The question isn’t “Can this be removed?” It’s “What is this doing?”

Maximalism can be purposeful. So can restraint. A shift in font weight establishes hierarchy. The space between two elements says whether they belong together. A shadow can explain elevation. An animation can preserve continuity.

When layout and typography communicate the idea completely, let them. Add another signal only when it contributes new information.

Use the quietest sufficient tool

02Typography

Begin at the base.

Start at 16 or 17. Then let the system grow from there.

A major-second scale creates a quiet, useful hierarchy for interfaces. The math gives the system coherence; judgment decides how each size is used.

02.1Color foundation

Gray, without the dead zone.

Use OKLCH. Shape the ramp instead of stepping through it blindly.

A cubic Bézier curve makes the changes in perceived lightness feel intentional across the full scale. These handles are a starting point, not a law.

03Gestalt

Space is syntax.

Spacing doesn’t decorate a relationship. It creates one.

Work on a 2px grid through 20px, then expand to a 4px grid. This preserves precision at small distances and creates rhythm at larger ones.

Spacing rule
2px grid

04Interface

Find the center of gravity.

Begin with a clear problem—or one specific interaction.

An interaction can be searching for a problem. That’s okay. The point is to give the work a concrete center before resolving the world around it.

01 / Frame

What problem matters?

Name the human need without prescribing the surface.

02 / Act

What is the core interaction?

Define the action and the response it deserves.

03 / Reveal

What must become visible?

Choose only the visual elements that make the exchange clear.

06Motion

Respect the platform’s pulse.

On the web: incredibly snappy. On touch: slower, fluid, physical.

Motion explains continuity, causality, and state. It never earns the right to make an interface feel slow.
