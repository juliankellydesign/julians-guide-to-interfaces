Principle № 001

Everythingserves a purpose

Every interface decision should communicate something or help someone complete an action.

This does not require minimalism. Detail is useful when it has a clear communication role.

How to construct
01Core principle

Every element has a job

For every decision, ask “What is this doing?”

A shift in font weight can establish hierarchy. Space can show whether elements belong together. A shadow can explain elevation. Animation can show continuity or cause and effect.

Use as many visual elements as the interface requires. Each additional element should contribute information.

02Content

Write direct, informative content

Every word should help someone understand, decide, or act

Content follows the same rule as every other part of the interface. Identify its purpose, state the relevant information clearly, and add style only when the style communicates something.

01

Identify the job

Decide whether the content names, explains, instructs, confirms, or helps someone recover.

02

State the information

Put the information needed for the next decision or action first.

03

Justify the style

Use tone, emphasis, metaphor, or humor only when it adds meaning.

Method default

Capitalization and punctuation

Use one scheme consistently. Change capitalization or punctuation only when the change communicates a different role or interaction.

Dash reference

Choose the dash by function

Use an em dash to change direction, an en dash to communicate a range, and a hyphen to join parts of a word.

Em dash — The pattern—once it is established—can be broken.

A pair pushes into an interruption and returns to the original sentence. An em dash followed by a space also attributes a quotation: Quotation text. — Author

pages 24 – 32

An en dash means “through” or “to.” Use thin spaces around it when it connects a range.

Use a hyphen inside compound words and required affixes. Do not substitute it for either dash, and avoid word hyphenation in interfaces.

03Typography

Start with the base size

Use 16px or 17px as the default base size

Generate the remaining sizes with a major-second ratio of 1.125. Change weight within a heading or sentence only to indicate interactivity. Judge the rendered hierarchy and adjust optically when needed.

Responsive typography

Recalculate from the rendered size

Font size, letter spacing, and line height are one system. When the rendered size changes, recalculate the other properties instead of preserving values chosen for a different size.

01Read the current size

Use the font size that actually renders between the responsive endpoints.

02Recalculate tracking

Pass the rendered size through the tracking curve, then apply caps and manual corrections.

03Recalculate line height

Preserve the role’s ratio, then snap the line box to the applicable spacing grid.

line height = round((rendered size × role ratio) ÷ grid) × grid 2px through 20px · 4px above 20px

Quotation marks, apostrophes, and primes

Use the glyph that matches the function

Quotation marks surround quotations. Apostrophes mark contractions, possession, and omitted characters. Prime marks denote measurements.

Quotation“ ”   ‘ ’

Opening and closing quotation marks face opposite directions.

Apostrophedon’t   ’26

03.1Color foundation

Build gray and color scales perceptually

Use 13 stops from pure white to near-black

Use stops 0, 50, 100–900, 950, and 1000. Stop 0 is pure white. Stop 1000 performs the role of black but is never pure black. Use the OKLCH curve as a starting model, then judge the rendered differences on actual displays.

The six base color scales—blue, red, orange, yellow, purple, and green—reuse the same stops and endpoints, hold one hue constant, and shape chroma with a cubic Bézier arch clamped to the sRGB gamut. They share their own lightness curve, which holds midtones lighter than the gray curve because sRGB chroma peaks near L 0.6–0.75. Equal stops share equal lightness across all six scales.

Lightness curvesgray (.35, .2, .55, .6)color (.5, .3, .6, .5)
Chroma archchroma = 0.16 × 4t(1 − t), clamped to 95% of sRGB
04Rhythm

Use space to show relationships

The distance between elements communicates whether they belong together

Use a 2px grid for values through 20px and a 4px grid for larger values. Take working tokens from the spacing ladder, which doubles its step as sizes grow. Keep repeated relationships consistent, then compensate optically when geometric alignment looks wrong.

Term

Gestalt means form or shape

Gestalt is a German word and a common design term for how people perceive separate elements as related groups or as a whole. Spacing is one of the clearest ways to communicate those relationships.

Rhythm and swing

Establish the pattern, then break it for a reason

Rhythm standardizes baselines, grids, tokens, type sizes, spacing, and repeated structures.

Swing changes one item to interrupt monotony or restore attention. If every item is different, there is no rhythm to break.

Swing also applies to type, color, and motion when the calculated result does not match human perception.

A surface can contain as many secondary actions as it needs, but only one action should read as primary. Reduce every other action according to its role.

06Imagery

Relate icons to type by function

Icons sit between type and image, and between content and interface

An icon used as interface shorthand should remain visibly distinct from text. A caret, chevron, or arrow used to complete a phrase behaves more like punctuation and should align closely with the typography.

07Motion

Match motion to the platform

Keep web motion under 200ms in most cases

Touch interfaces can use slower motion when it supports direct manipulation and continuity. In every case, motion should explain a change without making the interface feel slow.

Asides preserve personal and historical context. They are part of the documentation but are excluded from agent prompts and working guidance.

Aside 01

Crystal Silence

I learned Chick Corea’s “Crystal Silence” on vibraphone while growing up. Its approximate 76 BPM tempo is the personal reference behind my 48-frame animation scaffold at 60 fps.

Context for a timing default, not a motion rule
Aside 02

Study design history

I think the best way to learn design is to study history. Interfaces recombine graphic design and other forms of design. Study manuscripts before printing presses and the way dobby looms encoded repeatable patterns.

Historical context, not agent guidance
