# Size controls for the input method

## In brief

Choose control size according to the input method, the interface’s intended density, and the importance of the action. Mouse input supports smaller controls than touch input. On touch devices, the visible affordance and the interactive target can be different sizes.

## Let density communicate the product

Control size changes how an interface feels and who it appears to serve. Smaller desktop controls create the density expected in a power-user tool. Larger controls create a more approachable consumer interface.

Large controls on desktop should communicate emphasis rather than become the default. They are useful for a highlighted field, an emphasized onboarding or marketing action, or a single visible search field.

## Separate the affordance from the target

On touch devices, a visible control can be smaller than its interactive target. The visible affordance communicates what can be touched. The larger invisible target makes the control reliable to hit with a finger.

Do not place small affordances so close together that their touch targets compete or a person can easily trigger the wrong action. A pair of small controls stacked tightly together is not made usable merely by assigning each one a larger target.

## Use size to communicate emphasis sparingly

There is no useful hard upper limit for a touch control. Large controls can be appropriate when they fit the composition and the interaction. Judge them by taste, content, reach, and surrounding hierarchy.

On mouse-controlled surfaces, sizes above the normal control range should remain exceptions. If several large controls appear together, size no longer communicates emphasis.

## Working rules

- Choose control size for the actual input method rather than the device category alone.
- Use denser controls for power-user tools and more generous controls for consumer interfaces.
- Treat unusually large desktop controls as emphasized exceptions.
- Give touch controls a reliable finger-sized target even when the visible affordance is smaller.
- Do not allow adjacent touch targets to overlap or create likely mistaps.
- Do not make an affordance interactive when it is too small to communicate that it can be touched.
- Preserve an existing component system unless changing control sizing is part of the task.
