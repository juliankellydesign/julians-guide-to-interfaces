# Personal taste as scaffolding

## In brief

Use personal taste to create starting constraints and make decisions faster. A pet font, an animation technique, or a meaningful reference can reduce the burden of beginning from unlimited options. These preferences support the process but do not override the needs of the interface.

## Reduce decision load

Making design decisions can feel oppressive because every project presents a large number of valid choices. Reconsidering every choice from zero is slow and does not guarantee a better result.

Personal taste provides a place to start. It narrows the option space and allows the work to develop before every decision is fully resolved.

Useful scaffolding can include:

- A font I know well and enjoy using
- An animation style I want to explore
- A layout pattern from another part of my life
- A song, object, or memory that provides a useful rhythm or constraint

## Scaffolding is not a rule

Personal taste is a default input, not a reason to ignore the problem. Keep the preference when it helps the interface. Change it when the content, platform, audience, accessibility, or performance requires a different decision.

The preference does not need to be visible or explained to the user. Its job may be to help the designer decide faster and work with greater consistency.
