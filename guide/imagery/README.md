# Imagery

## In brief

Icons sit between type and image, and between content and interface. Their relationship to typography should change according to their role. An icon that acts as interface shorthand should remain visually distinct from text. An icon that decorates or extends text should align closely with the type.

## Iconography and type

Do not force every icon to behave like a special character from the font. Interface icons may be slightly larger than adjacent text and do not need to copy the font’s exact drawing conventions.

Carets, chevrons, and certain arrows are different. When they sit inside phrases such as “More” followed by a right chevron or “Website” followed by an up-right arrow, they behave almost like punctuation. Size and position them carefully so they feel integrated with the text.

See [`iconography-and-type.md`](iconography-and-type.md) for the full principle. For control padding patterns, see [`../methods/iconography/control-padding.md`](../methods/iconography/control-padding.md).
