# Treat empty and error states as opportunities

## In brief

Empty states, 404 pages, and no-network pages are opportunities for a little delight and for user education. The person has hit a dead end; the state page can soften the moment, show some personality, and teach what the state means and how to move forward. I usually try to make a really great animation for no-network pages.

## Dead ends carry low expectations

Nobody arrives at an empty list, a missing page, or an offline screen expecting much. That makes these states inexpensive places to exceed expectations: a small amount of craft reads clearly, and care shown at the product's edges suggests care everywhere else.

## Delight still serves a purpose

The core rule does not relax here—style is still used when it communicates something. In these states the flourish has a job: it softens an absence or a failure and keeps the moment from feeling like the product's fault line. Delight is the treatment; it does not replace the explanation.

## Educate at the moment of need

Each state is a moment where the person needs orientation, and the page should teach it directly:

- An empty state teaches what will fill the space and how to fill it.
- A 404 explains that the destination does not exist and offers a way back.
- A no-network page explains that the connection—not the product—is the problem, and what happens when it returns.

State copy is interface writing; the content principles apply.

## Invest in the no-network animation

I usually try to make a really great animation for no-network pages. The person is waiting with nothing to do, so the moment can absorb more motion than the rest of the interface: the animation acknowledges the wait and rewards the interruption. Any state animation still respects `prefers-reduced-motion`.

## Working rules

- Design empty states, 404s, and no-network pages deliberately rather than shipping defaults.
- Use each state to teach what it means and what the person can do next.
- Keep the flourish purposeful: it softens the moment, and the explanation still leads.
- Give the no-network page particular care; the wait can absorb a really great animation.
- Respect `prefers-reduced-motion` in any state animation.
- Write state copy with the content principles: direct, informative, and styled only with purpose.
