# Relate icons to type by function

## In brief

Icons are the intermediate step between type and image, and between content and interface. Decide whether an icon refers to the interface or behaves as part of a piece of text. That role determines how closely it should match the typography.

## Interface icons should remain distinct

When an icon is shorthand for an object, action, or part of the interface, it should feel different from the text around it. It may be slightly larger than adjacent type, and its design does not need to follow the font’s exact stroke, proportion, or drawing conventions.

Trying to make every interface icon look like a special character from the font can remove the distinction between reading and acting. The icon belongs to the interface and should remain identifiable as an interface element.

## Textual icons should behave like type

Some icons decorate, qualify, or complete text. Carets, chevrons, and certain arrows often perform this role.

Examples include:

- “More” followed by a right chevron
- “Website” followed by an arrow pointing up and to the right

These icons behave almost like punctuation. Their size, baseline, spacing, and optical position should be tuned carefully against the text. They should feel closer to the type choices than an icon used as standalone interface shorthand.

## Use the relationship to communicate the role

If the icon refers to the interface or acts as shorthand for something, preserve a visible distinction between icon and text. If the icon decorates or extends the text, make it feel closely related to the typography.

This is a functional distinction. It tells a person whether to interpret the icon as part of what they are reading or as a control or object they can act on.

## Judge the result optically

Font metrics and icon bounds are mathematical boxes, not the visible shapes people perceive. Adjust size, baseline, and spacing until the relationship communicates the intended role. Use the measurements as a starting point and the rendered relationship as the test.
