# Apply capitalization and punctuation

## In brief

Use Title Case for the product or app name at the highest level. Use sentence case for interface headings and body copy. Omit closing punctuation from headings and interactive labels. End body copy with a period. Use other punctuation only when it communicates function.

## Capitalization

Use Title Case for the top-level product or app title. This is the name that may appear outside the interface or at its highest level, including:

- A web app’s browser-tab title
- A mobile app’s home-screen name
- The app name at the top of the interface

Use sentence case for headings within the interface. Proper nouns retain the capitalization required by grammar.

| Role | Default | Example |
| --- | --- | --- |
| Top-level product title | Title Case | Julian’s Guide to Interfaces |
| Interface heading | Sentence case | Choose a font weight |
| Body copy | Sentence case | Use weight to communicate hierarchy. |

## Closing punctuation

- Interface headings do not end with closing punctuation.
- Body copy ends with a period.
- Buttons and other interactive labels do not end with a period.
- Exclamation points are almost never used.

## Punctuation that communicates interaction

A punctuation mark or punctuation-like glyph is useful when it explains what an interaction will do.

- A chevron or arrow can follow an interactive label as a punctuation-like glyph: `More ›`.
- A button that opens a modal often ends with an ellipsis to indicate that more steps follow: `Settings...`.
- A suitable glyph can communicate that continuation instead of an ellipsis.
- A question mark is rare but can identify an interactive route to help or support: `Need help?`.

## Working rules

- Choose one capitalization and punctuation scheme for the interface and apply it consistently.
- Use Title Case only for the top-level product or app name and where grammar requires it.
- Use sentence case for interface headings and omit closing punctuation.
- Use sentence case for body copy and end it with a period.
- Omit periods from buttons and interactive labels.
- Add an ellipsis, chevron, arrow, or question mark only when it communicates the interaction.
- Preserve an existing content system unless replacing it is part of the task.
