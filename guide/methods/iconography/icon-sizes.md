# Size icons from the tapering scale

## In brief

Use `20` as the workhorse icon size, sprinkle in `16` and `24`, and reserve `12` and `32` for rare cases. Pair icon sizes with text sizes consistently—a `20` icon always goes with `16` text—unless the icon is a chevron or arrow being tuned optically against its phrase.

## The sizes

| Frequency | Sizes |
| --- | --- |
| Mostly | `20` |
| Sprinkled | `16`, `24` |
| Rare | `12`, `32` |

The frequencies are part of the scaffold, not just the values: the further a size sits from `20`, the less often it should appear. All five sizes land on the spacing ladder, so icons share their rhythm with the layout around them.

## Pair sizes with text

When an icon accompanies text, hold the pairing constant everywhere it appears: a `20` icon always goes with `16` text. This is the one pairing I have fixed so far; derive others with the same discipline—one icon size per text size, applied everywhere—and record them as they settle.

## The chevron and arrow exception

Chevrons and arrows completing a phrase behave like punctuation and are tuned optically against that text. They may take a size off the pairing table when the rendered relationship requires it.

## Working rules

- Use `20` for most icons; let `16` and `24` appear occasionally and `12` and `32` rarely.
- Keep the frequency taper as part of the system; a second everywhere-size means the system has split.
- Pair `20` icons with `16` text, and keep any other pairing consistent everywhere it appears.
- Let chevrons and arrows leave the pairing for optical tuning.
- Preserve an existing interface's icon sizes unless replacing them is part of the task.
